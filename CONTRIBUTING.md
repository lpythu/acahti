# Contributing

Run the README checks before submitting a pull request. Keep MCP, REST and UI
operations behind the same catalog and authorization rules. Include regression
coverage when changing authentication, permission checks or merge conditions.

Use example.com endpoints and synthetic fixtures. Never include a live .env,
credentials or customer data. Contributions to Acahti-owned code are Apache-2.0;
retain third-party notices. Discuss new services or protocol changes in an issue
before implementation. See architecture.md for the current design.
