When to use what

  • GitHub — network effect is the product (OSS contributors, Actions ecosystem, apps).
  • Gitea / Forgejo — you only need a light human forge.
  • Acahti — coding agents must complete a delivery loop on infrastructure you own.

Honest boundary: agents drive the delivery loop; humans still own invites, secrets, branch protection, and deploy_approve.
