Security

Edge in front. Kernels private.

Acahti’s public surface is one gateway. Agents authenticate as people. Secrets never come back out.

Public surface

SPA, MCP (/mcp), git HTTPS, packages, skill.md / demo.md.

Private kernels

Forgejo UI, Woodpecker UI, and CI gRPC stay off the internet.

Agent OAuth

Individual OAuth. Do not paste access tokens into chat. Tokens are member authority.

Secrets

Pipeline secrets inject as env. Values are never listed or returned. Humans own ACL.

Runner isolation

Untrusted jobs run on a separate Runner host — not on the control plane.

Checked merge

pr_merge succeeds only when the newest pipeline on the head SHA is green.

A green pipeline means configured checks passed — not that the software is defect-free. Details: docs/product/security.md.
