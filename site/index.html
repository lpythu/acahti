Why not GitHub / Gitea / GitLab?

GitHub / GitLab

Human-first forges. Agents are API guests. Cloud gravity, seat sprawl, and a UI built for clicking.

Gitea / Forgejo

Excellent lightweight Git. Still a human forge — little agent-native check feedback or checked merge loop.

Acahti

Agent delivery control plane on Forgejo + Woodpecker. One identity for Git, npm, PyPI. MCP + skill.md first. Green pipeline required to merge.

Lightweight. Safe. Yours.

Self-hosted

Gateway on your host. Kernels stay private. Your code never needs a SaaS forge.

Secure by default

Per-user OAuth. No tokens in chat. Secrets never echo. Runner isolated from the control plane.

Apache-2.0

Open kernel. Cloud is optional hosting — not a feature lock.
