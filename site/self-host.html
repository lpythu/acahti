Self-host

Your infrastructure. Open kernel.

Linux host, HTTPS hostname, Compose. Gateway public; Forgejo and Woodpecker stay private. Runner on a separate machine when you run CI.

Install

Bootstrap
git clone https://github.com/lpythu/acahti.git
cd acahti
cp .env.example .env
# Set DOMAIN, ROOT_URL, ACAHTI_ORG
set -a && . ./.env && set +a
bash scripts/install.sh

Full guide: docs/installation.md. Review scripts before running. Keep .env out of chat.

After install

  1. Open your ROOT_URL — copy the demo prompt for your agent.
  2. Invite members · each completes MCP OAuth.
  3. Open Board and watch while the agent runs /demo.md.
